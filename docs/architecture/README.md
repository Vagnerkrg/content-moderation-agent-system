# Arquitetura do Sistema

## Sistema de Moderação de Conteúdo Assistido por IA

Este diretório contém a documentação arquitetural do sistema multiagente desenvolvido utilizando LangGraph.

## Objetivo

Documentar:

- componentes do sistema;
- responsabilidades dos agentes;
- fluxo de execução;
- gerenciamento de estado;
- pontos de intervenção humana.

## Documentos

### system-overview.md

Visão geral do sistema e seus componentes principais.

### agent-design.md

Descrição dos agentes, responsabilidades e comunicação entre eles.

### workflow.md

Descrição do fluxo de execução do grafo LangGraph.
